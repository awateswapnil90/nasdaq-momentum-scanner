How each column is calculated
  • Return % — Close today ÷ Close P bars ago − 1. With several periods ticked, the weighted average of each period's return using the Weight row.
  • Sharpe Return — each period's Return % ÷ its annualised volatility % (stdev of daily returns × √252), weighted the same way.
  • Volatility % — annualised volatility over the longest ticked period.
  • Retracement % — for 52W High / ATH: how far Close is below the high. For 52W Low / ATL: how far Close is above the low.
  • RSI — Wilder's RSI on Close, period from condition 5. EMAs — on Close, seeded with an SMA (same as TradingView).
  • TTM Sales / TTM Profit — sum of the latest 4 quarters of Total Revenue / Net Income (Yahoo Finance). Rising = higher than the TTM ending 1 (or 2) quarter(s) earlier, which is the same as the latest quarter beating the same quarter a year ago. Stocks with no quarterly data fail these two conditions. Quarterly results are the latest available, even when you scan an earlier date.
  • Avg Vol — the volume statistic chosen in the Volume row (average or median over the chosen days).
  • Prices are split/dividend adjusted (Yahoo Finance), so values can differ slightly from unadjusted charts.
